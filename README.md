# PartyRock Task Scheduler 🧠⚡

An AI-driven task scheduling app built with AWS PartyRock. The goal? Simplify your day with actionable breakdowns, smart timing, and tailored productivity tips — all powered by generative AI.

## 🔧 Features
- Breaks down daily tasks into logical steps
- Assigns time estimates per task
- Offers custom tips for efficiency and focus
- Built entirely with AWS PartyRock (no-code)

## 🧠 Prompt Template
"Develop a 'Daily Task Scheduler Application' aimed at enhancing productivity and organization. This app should be able to handle multiple tasks, and prompt the user to assign a time associated with the task. The app will then break down the task in the most logical and ethical ways, providing pleasing feedback and task execution."
